**Actions** run custom JavaScript when an event occurs in an Embeddable. Events are started by **Triggers** — for example, a button click or a page load.

Actions receive [User Data](/features/user-data), helper functions (such as `setUserData` and `triggerAction`), and context about what triggered them. They run **client-side** in the main window, so they can use `window`, `document`, and `localStorage`.

## Create an Action

<Steps>
  <Step title="Add the Action">
    - Open the **Logic** sidebar and go to the **Actions** tab.
    - Click **+ Add New Action**.
    - Give it a name (for example, "Send Data to Klaviyo").
    - Click **Add**.
  </Step>
  <Step title="Write the code">
    - Put your JavaScript inside the `output()` function.
    - The first argument is User Data; the other arguments are described in [Custom code](/guides/custom-code).
  </Step>
</Steps>

## Execution environment

Because Actions run in the main window, you can:

- Manipulate the DOM.
- Read and write `localStorage`.
- Call frontend functions you expose on `window` (for example, `window.logInToApp()`).

<Warning>
  Do not put API secrets or other secure credentials in Actions. To call secured APIs (and avoid CORS issues), use the Embeddables Proxy API — ask Embeddables support for setup help.
</Warning>

## Example: send data to a backend

```js
function output(userData) {
  const dataToSend = {
    email: userData.email,
    name: userData.name,
    favorite_color: userData.favorite_color,
  };

  fetch("https://your-backend-url.com/", {
    method: "POST",
    body: JSON.stringify(dataToSend),
  });
}
```
