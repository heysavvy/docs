## What DataStream is for

Sometimes you want to send [User Data](/features/user-data) to an external service (for example Airtable) and keep updating the **same** record as the user fills in more fields.

Without DataStream, each send often creates a new row. DataStream updates the existing record so it always holds the latest data.

<Info>
  The Embeddables data pipeline processes the queue about once per minute, so data can be up to a minute behind.
</Info>

## Supported integrations

Today, only the [Airtable](/features/actions/airtable) integration supports DataStream. Tell the Embeddables team if you want it on another integration.
