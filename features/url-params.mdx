URL params let you control how an Embeddable loads when you open a **preview link** or a **live page** on your site. They are not available in the Builder or Web App.

## How to use them

1. Add the param to the page URL as a query string (for example, `?version=latest` or `?savvy_flow_version=latest`).
2. Use the **preview** key on Embeddables preview links (`engine.embeddables.com/preview...`).
3. Use the **live** key on your own site URLs.

Some keys still use the old "Savvy" brand prefix. Behavior is the same; naming will be updated over time.

## Available params

| Param on preview link | Param on live link | Possible values | Description |
| --- | --- | --- | --- |
| `version` | `savvy_flow_version` | `latest`, `staging`, `123` | Show a specific Embeddable version |
| `savvy_test` | `savvy_test` | `true`, `false` | Force test mode on (live) or off (preview) |
| `savvy_track` | `savvy_track` | `true`, `false` | Force analytics tracking on (live) or off (preview) |
| `static_render` | `static_render` | `true` | Render HTML only, with no interactivity |
| `[USER_DATA_KEY]` | `[USER_DATA_KEY]` | `[USER_DATA_VALUE]` | Prefill or force a User Data value (must be an experiment key or listed in allowed URL keys) |
