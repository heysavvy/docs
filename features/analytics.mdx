**Analytics** in Embeddables covers automatic capture, custom client-side events, server-side events, and conversion definitions you analyze in the Web App.

## Automatic capture

Embeddables automatically capture:

- **User Data** — the full [User Data](/features/user-data) object can be captured. You control which fields go to the Embeddables database versus local browser storage.
- **Events** — page views, and button clicks when **Capture clicks** is enabled on the button.

## Custom client-side events

Track custom events from an [Action](/features/actions) with `trackCustomEvent()`.

<Steps>
  <Step title="Create an Action and Trigger">
    - Go to **Logic** → **Actions** and click **+ Add New Action**.
    - Name it (for example, "Track X event") and click **Add**.
    - Attach a Trigger for the event (for example, a button click).
  </Step>
  <Step title="Call trackCustomEvent">
    Inside `output()`, use `helperFunctions.trackCustomEvent(eventName, properties)`.

    It returns `Promise<void>` — `await` it if delivery must finish before the next step.

    ```js
    function output(userData, helperFunctions) {
      helperFunctions.trackCustomEvent("got_recommendation", {
        recommendation_id: properties.recommendation_id,
        recommendation_name: properties.recommendation_name,
      });
    }
    ```
  </Step>
</Steps>

### Structured event payloads

For events that mix numeric metrics and categorical dimensions, use:

- **payload_metrics** — object of **numbers** (for example `order_value`, `revenue`, `duration_ms`).
- **payload_dimensions** — object of **strings** (for example `plan`, `currency`, `experiment_variant`).

```js
function output(userData, helperFunctions) {
  helperFunctions.trackCustomEvent("purchase_completed", {
    payload_metrics: {
      order_value: 99.99,
      revenue: 89.99,
      subtotal: 79.99,
      tax: 10.0,
    },
    payload_dimensions: {
      plan: "premium",
      bundle: "annual",
      purchase_type: "subscription",
      currency: "USD",
    },
  });
}
```

<Tip>
  Keep metric values as numbers and dimension values as strings. You can add any keys within those types.
</Tip>

## Conversion events

Conversions are a status you assign to events in the Embeddables Web App. Each conversion has a name, a type, and properties:

| Type | Properties |
| --- | --- |
| Page view | `page_key` |
| Button click | `button_key` |
| Custom event | `event_name` |

Conversions tied to a page or button appear on the relevant items in the Pages sidebar.
