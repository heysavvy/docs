**Version control** is built into the Embeddables Builder. Almost every edit is tied to a version you can preview before anything goes live, so you always know what users will see.

## Drafts and unsaved edits

Any change in the Builder (pages, text, [experiments](/features/split-testing), logic, and so on) becomes part of your unsaved edits.

- Edits are private to you and backed up as a **Draft** once the **Save** button stops spinning.
- Drafts are tied to the version you are editing from (usually the last saved version).
- When you return to the Builder — or switch to a version that has your unsaved edits — you can **resume the draft** or **discard it** and edit from the last saved version.

## Save and switch versions

Click **Save** (top-right) to write your changes to a **version**.

- Open the **Version Control** card to switch between versions created by you or teammates and preview that state of the Embeddable.
- You can edit from an older version and save again. Saving from an older version makes that the latest version **without** changes from versions after the one you edited from (you "skip" those changes).

<Note>
  The Builder warns you before you skip or overwrite intervening versions, and shows a "From version XXX" message in the Version Control card.
</Note>

## Staging and Production

1. When you are ready for review, click **Staging** (top-right) or push from the Version Control card.
2. When checks are done, open the Version Control card, select the version, and click **Production**.

<Note>
  A Staging version has no special runtime behavior beyond being marked for review. You can open it with the staging URL param (see below).
</Note>

## Preview versions with URL params

Use [URL params](/features/url-params) to preview versions before going live:

| Goal | Preview link | Live site |
| --- | --- | --- |
| Specific version | `version=123` | `savvy_flow_version=123` |
| Latest saved | `version=latest` | `savvy_flow_version=latest` |
| Staging | `version=staging` | `savvy_flow_version=staging` |

Preview links look like `engine.embeddables.com/preview...`. On your own site, use the `savvy_flow_version` form.

<Tip>
  See the full list of params in [URL Params](/features/url-params).
</Tip>
