Each workspace user has two attributes that control what they can do and what data they can see:

- **Role** — editing, publishing, and team management.
- **Data access level** — how much end-user data they can view.

## Roles

Roles define what actions a user can take.

| Role | Capabilities |
| --- | --- |
| **Admin** | Full editing and publishing. Can manage other users' roles and data access. Best for team leads. |
| **Publisher** | Can save and push Embeddables live. Cannot manage other users. |
| **Editor** | Can save Embeddables, but **cannot** push them live. Best for preparing changes for review. |

## Data access levels

Data access levels control what end-user data a person can view.

| Level | Access |
| --- | --- |
| **Data Privacy Officer** | Full access to all end-user data. Defines which fields are sensitive. Assign to **one** trusted person. |
| **Full Data Access** | All end-user data, including PII/PHI. Only for people who need it for their job. |
| **Anonymized Data Access** | Anonymized data only — PII and health info are hidden. Safest default for most users. |

## Change roles and permissions

<Warning>
  You must be an **Admin** to change roles and permissions.
</Warning>

1. Open **Settings** in the sidebar.
2. Select the **Team** tab.
3. Find the user in the table.
4. Use the dropdowns to update their **Role** and **Data Access Level**.

## Tips

- Assign **Data Privacy Officer** to a single person who understands privacy requirements.
- Prefer **Anonymized Data Access** for most teammates.
- Grant **Full Data Access** only when required.
- Review roles and access levels regularly as the team changes.
