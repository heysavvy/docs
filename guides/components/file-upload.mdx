The **File Upload** component lets users upload one or more files. Upload results are stored in [User Data](/features/user-data) under the component key.

Configure it through **Configuration**, **Content**, **Validation**, and **More**.

## Configuration

<AccordionGroup>
  <Accordion title="User Input">
    Whether a file is required before the user can proceed.

    <Info>
      Shared setting for Input Box, Option Selector, Button, Calendly, File Upload, and PayPal.
    </Info>
  </Accordion>

  <Accordion title="Upload type">
    Which file kinds are accepted:

    | Value | Meaning |
    | --- | --- |
    | `all` | All types |
    | `image` | Images only |
    | `audio` | Audio files |
    | `video` | Video files |
    | `doc` | Documents |
    | `custom` | Custom MIME / extension list via **Custom upload type** |
  </Accordion>

  <Accordion title="Custom upload type">
    Custom accept list when **Upload type** is `custom`.
  </Accordion>

  <Accordion title="Multiple">
    Allow more than one file in a single upload.
  </Accordion>

  <Accordion title="Files max limit">
    Maximum number of files when multi-upload is enabled.
  </Accordion>

  <Accordion title="Upload file">
    Whether selected files are uploaded (as opposed to only selecting locally, depending on your flow setup).
  </Accordion>
</AccordionGroup>

<AccordionGroup>

## Design elements

In the Design sidebar you can style:

- **Uploader** — the upload area.
- **Label** / **Sub label** — label text.
- **File list** / **File item** — list of uploaded files (when shown).

See [Design](/features/design) for tags, breakpoints, and states.
