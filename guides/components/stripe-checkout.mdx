The **Stripe Checkout** component accepts payments inside your Embeddable using Stripe (Payment and Express Checkout).

This page is a short component overview. Full setup, configuration, and troubleshooting live under Payments.

<Card
  title="Accepting Stripe payments in Embeddables"

  Complete Stripe guide: checkout types, keys, setup steps, pricing, customer data, UI options, events, and troubleshooting.

## What this component does

- Renders Stripe Payment and/or Express Checkout elements in your flow.
- Supports payment, setup, and subscription checkout modes.
- Can write payment-related IDs and status into [User Data](/features/user-data).
- Can trigger [Actions](/features/actions) on payment attempted, success, failure, mount, and unmount.

## Design elements

In the Design sidebar you can style:

- **Payment box** — payment form container.
- **Payment form** — the form element.
- **Stripe checkout button** — submit / pay button.
- **Message list** — container for messages.
- **Error message** / **Success message** — result text.

See [Design](/features/design) for tags, breakpoints, and states.
